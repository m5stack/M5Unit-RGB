◆ Order

enum class m5::unit::rgb::Order : int8_t
strong

Color order.

Each name lists the bytes in the order they are sent, e.g. grb24 sends G, R, B

Enumerator
unknown 

Not set (begin() fails)

hasWhite 

First 32-bit order; orders >= hasWhite carry a white channel.

wrgb32 

Same value as hasWhite.
